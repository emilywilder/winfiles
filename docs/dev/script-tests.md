# Script tests

How the Pester tests in `tests/scripts/` run the scripts, and what each test file covers. The fakes and what isn't tested are in [testing.md](testing.md).

`Invoke-Script` runs each script in a child pwsh, with `USERPROFILE` (which pwsh's `$HOME` follows) pointed into `TestDrive:` wherever the script writes under `~`, so no test writes the real `run.log`. Scripts that run under Windows PowerShell 5.1 are tested under 5.1. Trade-off: a test that calls the fake `dsc` costs about 2s, for running the scripts' real path to dsc.

| Test file | What it covers, beyond the obvious |
|---|---|
| `ConvertTo-FlatConfiguration` | each refusal; the tag order, `-Batch`, `-First` and the aggregate, with the real `yq` on small documents. It also flattens every entry in `dsc/`, so a name used twice across modules fails here rather than at the start of an install, and checks that a home entry with a distribution has `Winfiles.Wsl/Wsl` in its host's system entry. `winfiles.ps1 flatten` is tested only for its failure, since a flat copy goes to the real `~/.local/state` |
| `Invoke-Configuration` | the batches it runs and in which order; a resource reporting `_restartRequired` pulled into a first `restart` batch, and none when nothing reports one; 194 logged as a stop for a restart; a failed discovery stopping the run before anything is applied; the one total of a `test` |
| `Set-RestartStage`, `Find-RestartResource` | the dsc operations and their order, what it tells the person, failures and refusals; the `winfiles-restart:` lines, a resource inside an Include result, an empty answer, a failed test |
| `Test-Winfiles` (also `Set-Winfiles`) | a small flat document answered by the fake `dsc`; refusing a document with an Include; `-TotalsFile`; the `apply` phase for a batch name |
| `dsclog` | `Get-ResourceResult`, `Get-RestartReport` and `Get-ResourceProblem` on each result shape DSC 3.3.0 gives |
| `restart` | the pending-restart reasons, faking only the servicing key and the computer's two names |
| `Commands` | the runner: reading the table and refusing its mistakes, the order of dependencies and steps, defaults, usage errors, and the real `install`. Then `winfiles.ps1` in a checkout in `TestDrive:` with a table of its own, a fake `Invoke-Clean.ps1` and a fake gsudo: requirements checked before anything runs, one clean run and one `Invoke-AsAdmin.ps1` call, the UAC message and `run.log` lines, exit codes (3010 included) coming out unchanged, the list , `help` and the real `resume` command's steps; a `resumable` command clearing an earlier run's entry once, and giving its steps its arguments in `WINFILES_RESUME` |
| `Invoke-As` | `Invoke-AsAdmin.ps1` and `Invoke-AsUser.ps1` with the fake gsudo, and `privilege.ps1` through them |
| `install.cmd` | the real `install.cmd`, with this machine's mise and pwsh, but only with a host that has no configuration, so `winfiles.ps1 install` stops at its requirements before UAC or any change: its arguments, exit code, working folder and clean environment, and that it writes and then removes the RunOnce entry |
| `resume` | arming and clearing the entry, in this process, and the functions of `restart.ps1` that stop a run, in a child (`Restart-Windows` only with `-WhatIf`, so nothing restarts). The RunOnce key is one of the test's own (`WINFILES_RUNONCE_KEY`), never the real one |
| `Wait-Resume` | the script in a child pwsh, with its own restart-pending key under HKCU (`-RebootPendingKey`), a `TcpListener` for winget's source (`-SourceHost`, `-SourcePort`, `-WaitSeconds`) and an empty line on stdin for Enter; its `[resume]` lines |
| `Invoke-Clean`, `Start-Winfiles`, `miseignore` | commands under the real mise; the version check under 5.1; `Start-Winfiles.ps1` under 5.1 with and without mise on `PATH`; the mise configuration to ignore under pwsh and 5.1, and against this machine's `mise config ls --json` |
| `Initialize-Winfiles`, `bootstrap.cmd` | the bootstrap's checks and what it prints, not its installs; the App Installer retry's failure path (a fake winget that always answers `0x8A15000F`), skipped elevated; `bootstrap.cmd` from a copy of the repo without `mise.toml`; CRLF and a `.gitattributes` entry for every root `.cmd` |
| `Get-ManualInstaller` | the real Uninstall keys, read only, with a program installed on the machine and ones that can't be; downloads recorded by the fake winget; a list with non-ASCII text read as written, which fails under `chcp 437` without `Invoke-Yq`'s encoding ([reference](../reference/windows.md#a-native-commands-output-and-the-consoles-code-page)) |
| `Watch-TestVmLog` | the watch scriptblock, taken from the script's AST and run under `powershell.exe` against scratch logs ([reference](../reference/test-vm.md#following-logs-in-the-vm)) |
| `Help` | that Get-Help reads every script's synopsis |
| `Invoke-Lint` | the real PSScriptAnalyzer on small scripts in `TestDrive:` (a finding named by file, line and rule; the layout rules only for a test file; the 115-character limit), and on the whole repo, which has to have no findings |
